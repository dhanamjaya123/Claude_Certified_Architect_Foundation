# Official Sources / Further Reading

This study pack was cross-checked against current public Anthropic documentation available at the time it was prepared.

1. **Claude Platform — How tool use works**  
   https://platform.claude.com/docs/en/agents-and-tools/tool-use/how-tool-use-works  
   Key topics: client tool loop, `tool_use`, `tool_result`, stop reasons, server-side loop.

2. **Claude Platform — Build a tool-using agent**  
   https://platform.claude.com/docs/en/agents-and-tools/tool-use/build-a-tool-using-agent  
   Key topics: agentic loop, conversation history, multiple/parallel tool calls, error handling.

3. **Claude Code — Create custom subagents**  
   https://code.claude.com/docs/en/sub-agents  
   Key topics: delegated subagents, separate context, tool restrictions, resuming subagents.

4. **Claude Code — Hooks reference**  
   https://code.claude.com/docs/en/hooks  
   Key topics: lifecycle hooks such as SessionStart, PreToolUse, PostToolUse, Stop, SubagentStart/Stop, task events.

5. **Claude Code — Agent SDK hooks**  
   https://code.claude.com/docs/en/agent-sdk/hooks  
   Key topics: blocking dangerous operations, auditing, human approvals, lifecycle and state management.

6. **Claude Code — Run agents in parallel**  
   https://code.claude.com/docs/en/agents  
   Key topics: subagents and parallel work patterns.

7. **Claude Code — Tools reference**  
   https://code.claude.com/docs/en/tools-reference  
   Key topics: built-in tool concepts and the Agent tool for subagent spawning.

> Product names, model names, tool names, hook events, and certification blueprints can change. Use the official exam guide as the source of truth for the exact exam scope.
